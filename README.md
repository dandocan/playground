# Playground

A monorepo starter with a NestJS API and a Next.js web app.

## Requirements

- Node.js 20.19 or later
- npm

## Install

```sh
npm install
```

## Development

Run each app in a separate terminal:

```sh
npm run dev:api
npm run dev:web
```

The API is available at `http://localhost:3001` and the web app at
`http://localhost:3000`.

## Checks

```sh
npm run build
npm run lint
npm test
npm run test:e2e
```
